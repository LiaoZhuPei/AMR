
在信号处理中，**希尔伯特变换（Hilbert Transform）** 与 **解析信号（Analytic Signal）** 是密不可分的两个核心概念。它们最主要的目的，是**把现实中真实的“实数信号”，转换为一个“没有负频率分量”且“包含瞬时信息”的复数信号**。

下面用“直观背景 $\rightarrow$ 希尔伯特变换 $\rightarrow$ 解析信号 $\rightarrow$ 核心用途”的脉络为你详细拆解。

---

### 一、 核心动机：为什么需要它们？

现实世界中传感器采集的信号都是**实信号**（如声音、振动、电压）。
根据傅里叶变换的性质，任何实信号的频谱都是**共轭对称**的：
* 既有正频率部分，也有负频率部分。
* 负频率在数学上是必需的（为了抵消虚部，让反变换结果保持为实数），但在物理信息上它和正频率是**完全冗余**的。

例如：对于 $\cos(\omega_0 t) = \frac{1}{2} e^{j\omega_0 t} + \frac{1}{2} e^{-j\omega_0 t}$，它在频域上有两个峰：$+\omega_0$ 和 $-\omega_0$。
但如果我们把信号写成单边旋转向量 $e^{j\omega_0 t} = \cos(\omega_0 t) + j\sin(\omega_0 t)$：
1. 它只包含正频率 $+\omega_0$。
2. 它的实部是原信号 $\cos(\omega_0 t)$，虚部是与原信号**相位差 90 度**的 $\sin(\omega_0 t)$。

**希尔伯特变换**正是实现“给任意信号产生一个 90 度相移分量”的数学工具；而由此构成的包含正频的复信号，就是**解析信号**。

---

### 二、 希尔伯特变换（Hilbert Transform）

希尔伯特变换本质上是一个**理想的 $90^\circ$ 全通移相滤波器**：它不改变信号各频率成分的幅度，只改变相位。

#### 1. 频域特性（直观理解）
希尔伯特变换的频域传递函数定义为：
$$H(f) = -j \operatorname{sgn}(f) = \begin{cases} -j = e^{-j \frac{\pi}{2}}, & f > 0 \\ 0, & f = 0 \\ +j = e^{+j \frac{\pi}{2}}, & f < 0 \end{cases}$$

* 对**正频率**分量：乘以 $-j$，相当于**滞后 $90^\circ$（$-\frac{\pi}{2}$）**。
* 对**负频率**分量：乘以 $+j$，相当于**超前 $90^\circ$（$+\frac{\pi}{2}$）**。
* 直流分量（$f=0$）：变为 0。

> **典型示例：**
> * $\mathcal{H}\{\cos(\omega t)\} = \sin(\omega t)$
> * $\mathcal{H}\{\sin(\omega t)\} = -\cos(\omega t)$

#### 2. 时域定义
在时域中，希尔伯特变换表现为原信号 $x(t)$ 与冲击响应 $h(t) = \frac{1}{\pi t}$ 的卷积：
$$\hat{x}(t) = \mathcal{H}\{x(t)\} = x(t) * \frac{1}{\pi t} = \frac{1}{\pi} \text{P.V.} \int_{-\infty}^{\infty} \frac{x(\tau)}{t - \tau} d\tau$$
*（注：$\text{P.V.}$ 表示柯西主值，因为积分在分母为 0 处存在奇异点）。*

### 三、 解析信号（Analytic Signal）

有了希尔伯特变换，我们就可以构造解析信号。

#### 1. 定义
对于实信号 $x(t)$，其对应的**解析信号** $z(t)$ 定义为一个复数信号：
$$z(t) = x(t) + j\hat{x}(t)$$
其中：
* 实部是**原始信号** $x(t)$。
* 虚部是原始信号的**希尔伯特变换** $\hat{x}(t)$。

#### 2. 频域魔法：消除负频率
我们在频域观察 $z(t)$ 的傅里叶变换 $Z(f)$：
$$Z(f) = X(f) + j \hat{X}(f)$$
代入 $\hat{X}(f) = -j \operatorname{sgn}(f) X(f)$：
$$Z(f) = X(f) + j \big(-j \operatorname{sgn}(f) X(f)\big) = X(f) [1 + \operatorname{sgn}(f)]$$

根据符号函数 $\operatorname{sgn}(f)$ 的取值：
$$Z(f) = \begin{cases} 2X(f), & f > 0 \\ X(0), & f = 0 \\ 0, & f < 0 \end{cases}$$

**结论：** 解析信号在频域中**完全去除了负频率部分**，正频率部分的幅度**翻倍**（以保持能量守恒）。

### 四、 为什么解析信号如此重要？

将一维的实信号扩展到二维复平面的解析信号后，我们可以轻松提取信号的时变特征：

#### 1. 瞬时包络（Instantaneous Amplitude / Envelope）
$$A(t) = |z(t)| = \sqrt{x^2(t) + \hat{x}^2(t)}$$
* **物理意义**：它给出了信号幅度的动态变化包络线。在传统电路中需要二极管检波和低通滤波，而通过解析信号可以直接进行**理想包络提取**。

#### 2. 瞬时相位（Instantaneous Phase）
$$\phi(t) = \arg(z(t)) = \arctan\left(\frac{\hat{x}(t)}{x(t)}\right)$$
* **物理意义**：追踪信号在每一时刻振荡所处的状态角度。

#### 3. 瞬时频率（Instantaneous Frequency）
$$f(t) = \frac{1}{2\pi} \frac{d\phi(t)}{dt}$$
* **物理意义**：相位随时间的变化率，代表信号在“当前这一瞬间”的振荡频率（对于调频信号、啁啾 Chirp 信号尤为重要）。

### 五、 核心应用场景

1. **通信系统（单边带调制 SSB）：**
   常规双边带（DSB）调幅会占用两倍带宽。利用希尔伯特变换去掉一个边带（只保留正频率或负频率），可以节省一半的频谱带宽。
2. **包络检波与解调：**
   在雷达、声呐与医学超声（B超）中，回波通常是高频载波被反射体包络调制的信号。通过解析信号计算 $|z(t)|$ 即可无失真地恢复出目标的反射强度包络。
3. **机械故障诊断（振动分析）：**
   齿轮或轴承损坏时，往往会在高频固有共振频率上产生周期性的低频冲击（调幅现象）。工程师对振动信号做希尔伯特变换提取包络，再对包络做频谱分析（称为**包络谱**），就能清晰看到故障特征频率。
4. **希尔伯特-黄变换（HHT）：**
   配合经验模态分解（EMD），用于处理高度非线性、非平稳的自然物理信号（如地震波、脑电信号 EEG）。
