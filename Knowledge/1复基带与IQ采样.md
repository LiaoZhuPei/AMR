# 复基带模型与 IQ 采样：为什么需要 I/Q 两路？

理解这个问题，最重要的是先建立一个认识：

通信系统通常不是直接处理高频载波上的信号，而是把信号转换到一个更容易处理的“基带”表示中。为了完整地描述信号的幅度和相位变化，我们通常使用复数形式的基带模型，而 I/Q 两路正是实现这种复数表示的两条实数通道。

我们从“基带”开始，一步步解释。

# 一、什么是基带？从基带理解通信系统

## 1. 从一个最简单的信号说起

假设我们要通过无线电发送一个信息。比如，我们想发送一个随时间变化的信号 \\(m(t)\\)。

这个信号可以是：

- 语音经过处理后形成的电信号；
- 数字通信中经过调制形成的波形；
- 代表数字比特的脉冲序列。

我们先不考虑如何通过天线发送，只关注这个信号本身。

通常，信息信号的频率相对较低。例如，语音信号的主要频率成分在几千赫兹的范围内，而无线通信使用的载波频率可能是几百 MHz，甚至几 GHz。

直接把低频信息信号送到天线上，往往不适合高效地进行无线传输。因此，我们需要把它搬移到一个更高的频率范围。

这个过程就是调制。

## 2. 什么是基带？

基带（Baseband）是指信号未经上变频搬移到射频载波附近时所处的频率范围。

例如，假设一个信号的频谱主要分布在零频附近：

示意图：基带频谱围绕零频展开。实际信号的带宽和频谱形状取决于具体的调制方式。

注意：这里说的“基带”并不意味着信号必须包含一个真正的 0 Hz 直流分量，而是强调它的频谱位于零频附近。

## 3. 什么是载波？为什么需要载波？

载波（Carrier）可以理解为一个高频振荡信号：

\\[ c(t)=\cos(2\pi f_c t) \\]

其中：

- \\(f_c\\)：载波频率；
- \\(t\\)：时间。

例如，假设载波频率为 2.4 GHz，那么载波每秒振荡 24 亿次。

我们可以把信息加载到载波的幅度、相位或频率等参数上，再通过天线发送出去。

例如，最简单的幅度调制可以写为：

\\[ s(t)=m(t)\cos(2\pi f_c t) \\]

这里，低频信息 \\(m(t)\\) 控制高频载波的幅度。

从频谱角度看，乘以一个高频余弦，相当于把原来位于零频附近的基带频谱搬移到载波频率附近。

那么，既然通信系统可以在基带处理信号，为什么还要引入复数？为什么还需要 I/Q 两路？

这就涉及复基带模型。

# 二、什么是复基带模型？

## 1. 从实数信号到复数信号

首先，实际的电压、电流以及天线上的射频电磁波，都可以用实数物理量来描述。

但在数学建模时，我们可以用复数来表示一个信号的两个独立分量：

\\[ x(t)=I(t)+jQ(t) \\]

其中：

- \\(I(t)\\)：同相分量（In-phase）；
- \\(Q(t)\\)：正交分量（Quadrature）；
- \\(j=\sqrt{-1}\\)：虚数单位，满足 \\(j^2=-1\\)。

这里的 \\(I(t)\\) 和 \\(Q(t)\\) 都是实数信号，只有将它们组合起来，才构成复数信号 \\(x(t)\\)。

复基带模型，就是用一个复数信号 \\(x(t)\\)，在数学上描述原本位于高频载波附近的调制信号。

它的关键优势是：不必在基带模型中直接处理 GHz 量级的载波振荡，就能保留调制信号的幅度和相位信息。

## 2. 为什么叫“复基带”？

这个名字可以拆成两个部分理解。

| 名称                    | 含义                       |
| --------------------- | ------------------------ |
| 复（Complex）            | 使用复数表示信号，即 I 和 Q 两个实数分量  |
| 基带（Baseband）          | 把信号表示在零频附近，而不是直接围绕高频载波建模 |
| 复基带（Complex Baseband） | 用复数形式描述调制信号的基带等效表示       |

举个例子，假设：

\\[ x(t)=0.6+j0.8 \\]

这是一个复数信号。它的实部为 0.6，虚部为 0.8。

它也可以转换成极坐标形式：

\\[ x(t)=A(t)e^{j\phi(t)} \\]

其中：

\\[ A(t)=\sqrt{I^2(t)+Q^2(t)} \\]

\\[ \phi(t)=\operatorname{atan2}(Q(t),I(t)) \\]

对于上面的例子：

\\[ A=\sqrt{0.6^2+0.8^2}=1 \\]

\\[ \phi\approx53.13^\circ \\]

也就是说，一个复数同时携带了幅度和相位两方面的信息。

复基带的几何意义

I 是水平坐标，Q 是垂直坐标。复基带信号可以看成复平面上的一个向量，其长度表示幅度，角度表示相位。

当信号随时间变化时，\\(I(t)\\) 和 \\(Q(t)\\) 会同时变化，因此复数向量的长度和角度也会随时间变化。

## 3. 复基带信号如何对应真实的射频信号？

这是理解复基带模型最关键的一步。

假设复基带信号为：

\\[ x(t)=I(t)+jQ(t) \\]

与它对应的射频实信号，可以采用下面的约定：

\\[ \boxed{ s(t)=\operatorname{Re}\left\\{ x(t)e^{j2\pi f_ct} \right\\} } \\]

将复数展开：

\\[ \begin{aligned} s(t) &=\operatorname{Re}\left\\{ (I(t)+jQ(t))e^{j2\pi f_ct} \right\\}\\\ &=I(t)\cos(2\pi f_ct)\\\ &\quad-Q(t)\sin(2\pi f_ct) \end{aligned} \\]

因此：

\\[ \boxed{ s(t)=I(t)\cos(2\pi f_ct) -Q(t)\sin(2\pi f_ct) } \\]

这个公式告诉我们：

- I 路调制余弦载波；
- Q 路调制正弦载波；
- 两个载波相差 \\(90^\circ\\)；
- 两路信号叠加，形成最终的射频信号。

这里采用的是一种常见的复基带约定。其他资料可能使用不同的正负号或归一化系数，但基本原理相同。

到这里，我们已经可以回答一部分问题：复基带模型需要两个分量，是因为它要描述一个具有两个独立自由度的调制信号。

但为什么一定要选择相差 \\(90^\circ\\) 的两路？为什么不能用两路相同的余弦信号？

# 三、为什么需要 I/Q 两路？

## 1. 最核心的原因：单独一路不足以完整表示任意的幅度和相位

我们先考虑一个单频射频信号：

\\[ s(t)=A\cos(2\pi f_ct+\phi) \\]

其中：

- \\(A\\) 是幅度；
- \\(\phi\\) 是相位；
- \\(f_c\\) 是载波频率。

利用三角恒等式：

\\[ \cos(\alpha+\phi) =\cos\phi\cos\alpha-\sin\phi\sin\alpha \\]

可以将信号写成：

\\[ s(t)= A\cos\phi\cos(2\pi f_ct) -A\sin\phi\sin(2\pi f_ct) \\]

与复基带形式对比，就得到：

\\[ I=A\cos\phi \\]

\\[ Q=A\sin\phi \\]

这两个公式非常重要。

I 和 Q 分别对应相位在两个正交方向上的投影。

如果只保留 I 路，那么你只能获得 \\(A\cos\phi\\)，而不能在一般情况下单独确定 \\(A\\) 和 \\(\phi\\)。

例如：

- \\(A=1,\phi=0^\circ\\)，得到 \\(I=1\\)；
- \\(A=2,\phi=60^\circ\\)，得到 \\(I=1\\)。

两种信号的 I 分量完全相同，但它们的幅度和相位都不同。

只看 I 路，就无法区分这两个信号。

加入 Q 路后：

- 第一种情况：\\(Q=0\\)；
- 第二种情况：\\(Q=\sqrt{3}\\)。

两者就能够区分开来。

## 2. 为什么两路必须正交？

“正交”在这里可以直观理解为两路载波的相位差是 \\(90^\circ\\)。

假设我们选择：

\\[ c_I(t)=\cos(2\pi f_ct) \\]

\\[ c_Q(t)=-\sin(2\pi f_ct) \\]

它们的相位差为 \\(90^\circ\\)，并且在适当的整数周期内，乘积的平均值为零：

\\[ \int_0^T \cos(2\pi f_ct)\sin(2\pi f_ct)\\,dt=0 \\]

这里假设 \\(T\\) 覆盖整数个载波周期。

这意味着，在理想条件下，我们可以通过相关运算或同步解调，分别提取两路的信息，而不会让一路直接混入另一路。

如果两路使用完全相同的载波：

\\[ s(t)=I(t)\cos(2\pi f_ct) +Q(t)\cos(2\pi f_ct) \\]

那么：

\\[ s(t)=(I(t)+Q(t))\cos(2\pi f_ct) \\]

接收端只能看到两路的和，无法独立恢复 I 和 Q。

所以，正交载波不是随意选择的，而是为了让两个分量能够独立承载信息并被分离。

## 3. 通过一个具体例子理解 I/Q

假设我们希望发送一个幅度为 1、相位为 \\(45^\circ\\) 的信号。

那么：

\\[ I=\cos45^\circ=\frac{\sqrt2}{2} \\]

\\[ Q=\sin45^\circ=\frac{\sqrt2}{2} \\]

两路的数值相同，但它们调制的是不同的载波：

\\[ s(t)= \frac{\sqrt2}{2}\cos(2\pi f_ct) -\frac{\sqrt2}{2}\sin(2\pi f_ct) \\]

这与：

\\[ s(t)=\cos(2\pi f_ct+45^\circ) \\]

是等价的。

如果改变 I 和 Q，就可以改变合成信号的幅度或相位。

## 4. I/Q 两路与数字调制的关系

I/Q 的意义不仅在于数学建模，它还是数字通信中常见的调制方式的基础。

例如，QPSK（四相移键控）可以使用四个不同的相位来表示不同的符号；QAM（正交幅度调制）则可以同时利用幅度和相位的变化来表示符号。

这也解释了为什么在现代无线通信中，I/Q 数据如此常见。

# 四、什么是 IQ 采样？它和复基带模型是什么关系？

前面介绍的是连续时间信号。数字通信系统还需要把信号转换成计算机能够处理的离散数据。

## 1. 从连续信号到离散样本

假设接收端已经通过模拟电路把射频信号转换到了基带。

如果要交给数字信号处理器（DSP）或软件无线电（SDR）处理，就需要通过 ADC（模数转换器）进行采样。

对于复基带信号：

\\[ x(t)=I(t)+jQ(t) \\]

在采样时刻 \\(t=nT_s\\) 进行采样，可以得到：

\\[ I[n]=I(nT_s) \\]

\\[ Q[n]=Q(nT_s) \\]

于是：

\\[ \boxed{x[n]=I[n]+jQ[n]} \\]

这就是数字域的复基带采样序列。

每个采样时刻，系统会得到两个实数：一个 I 样本和一个 Q 样本。

需要注意，实际接收机可以使用两路 ADC，也可以通过其他硬件架构实现；“IQ 采样”描述的是得到 I/Q 两个离散分量这一结果，不是说所有设备都必须采用完全相同的硬件。

## 2. 接收机如何得到 I/Q 两路？

一种典型的正交接收机结构如下：

天线接收射频信号

低噪声放大器 / 射频前端

正交混频器

分别使用相差 90° 的本地振荡信号

I 路

低通滤波 → ADC

Q 路

低通滤波 → ADC

数字复基带序列

\\(x[n]=I[n]+jQ[n]\\)

接收机将输入信号分别与本地的正交载波混频，再通过低通滤波去除不需要的高频分量，便可得到 I/Q 基带信号。

理想情况下，若射频信号为：

\\[ s(t)=I(t)\cos(\omega_ct)-Q(t)\sin(\omega_ct) \\]

那么分别与 \\(\cos(\omega_ct)\\) 和 \\(-\sin(\omega_ct)\\) 混频并进行低通滤波，就能恢复与 I 和 Q 成比例的分量。具体增益取决于混频器和信号归一化方式。

## 3. 为什么不直接对射频信号采样？

直接对射频采样在一些系统中完全可行，但对高速 ADC、时钟和数字处理能力要求很高。

复基带处理通常具有以下优势：

- 降低采样和处理压力： 采样率可以根据基带信号带宽选择，而不一定要跟随高频载波频率。
- 便于实现数字调制与解调： 滤波、同步、均衡、信道估计等算法可以在复数域中统一实现。
- 完整保留幅度与相位： 对 QPSK、QAM 等调制方式尤其重要。
- 方便描述信道影响： 例如多径传播引起的幅度衰落和相位旋转，可以通过复数信道系数表示。

当然，直接射频采样、低中频采样等架构也很常见。复基带是一种高效的信号表示与处理方法，不代表所有接收机都必须先转换成模拟 I/Q。

# 五、最后总结：如何准确回答“为什么需要 I/Q 两路？”

可以从三个层次理解。

| 层次     | 核心问题                | I/Q 的作用                             |
| ------ | ------------------- | ----------------------------------- |
| 数学表示   | 怎样描述任意的幅度和相位？       | 用复数 \\(I+jQ\\) 表示两个独立分量             |
| 调制与解调  | 怎样让两个分量同时传输，并能分别恢复？ | 使用相差 90° 的正交载波                      |
| 数字信号处理 | 怎样把信号交给计算机处理？       | 采样得到 \\(I[n]\\) 和 \\(Q[n]\\)，形成复数序列 |

最重要的是，不要把 I/Q 理解为“把同一个信号复制两份”。

它们是同一个复基带信号的两个不同分量，分别承载正交方向上的信息。组合起来以后，才能完整表示调制信号的幅度和相位，并使接收端能够恢复这些信息。

如果要用一句话回答这个问题，可以说：

之所以需要 I/Q 两路，是因为单独一路实数信号通常不足以完整描述任意调制信号的幅度与相位；使用两路相差 90° 的正交分量，可以在保持信息完整性的同时，把高频射频信号转换为更容易进行数字处理的复基带信号。
