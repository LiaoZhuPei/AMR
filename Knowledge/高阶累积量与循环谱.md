你提到的 盲估计/统计特征（Blind Estimation / Statistical Features），主要用于无线通信中的调制识别（Automatic Modulation Classification，AMC）。核心思想是：即使不知道发射端发送了什么数据、也没有已知训练序列，仍然可以通过接收信号的统计规律，推断它采用了什么调制方式。

主要有两类特征：

1. 高阶累积量（HOC）：分析信号幅度、相位等统计分布的高阶特征，用于区分 QAM、PSK 等调制方式。
2. 循环谱（Cyclostationary Features）：分析信号中随时间周期性变化的统计特征，帮助从噪声和干扰中检测出通信信号。

下面分别解释。

# 一、高阶累积量 HOC（Higher-Order Cumulants）

## 1. 为什么需要高阶累积量？

假设接收到的基带信号为：

\\[ r[n]=s[n]+w[n] \\]

其中：

- \\(s[n]\\)：发送的调制信号。
- \\(w[n]\\)：加性高斯白噪声（AWGN）。
- \\(r[n]\\)：接收信号。

不同调制方式的信号分布不同。例如：

QPSK / 4-PSK

4 个星座点，通常分布在圆周上。

16-QAM

16 个星座点，分布在多个幅度层级上。

如果只观察平均功率等二阶统计量，某些不同调制方式可能很难区分。

高阶累积量则进一步描述信号分布的非高斯性、峰度和高阶结构，因此可以提供额外的识别信息。

## 2. 什么是累积量？

先从常见的统计量理解：

| 阶数 | 典型统计量  | 主要描述       |
| -- | ------ | ---------- |
| 一阶 | 均值     | 信号的平均值     |
| 二阶 | 方差、协方差 | 功率和相关性     |
| 三阶 | 三阶累积量  | 偏斜及非对称特征   |
| 四阶 | 四阶累积量  | 峰度及更高阶分布特征 |

高阶累积量和高阶矩不是完全相同的概念。以零均值实随机变量 \\(x\\) 为例：

\\[ C_4=E[x^4]-3(E[x^2])^2 \\]

这里：

- \\(E[x^4]\\) 是四阶矩。
- \\(E[x^2]\\) 是二阶矩。
- \\(C_4\\) 是四阶累积量。

累积量能够在一定条件下消除由低阶统计量组合而成的部分影响。

一个特别重要的性质是：理想高斯噪声的三阶及以上累积量为零。 这使得 HOC 在某些噪声环境下很有价值。

## 3. \\(C\_{42}\\) 和 \\(C\_{40}\\) 是什么？

在复基带通信信号中，常见的四阶累积量包括 \\(C\_{42}\\) 和 \\(C\_{40}\\)。

一种常见的定义方式是：

\\[ C\_{42}=E[|s|^4]-|E[s^2]|^2-2(E[|s|^2])^2 \\]

\\[ C\_{40}=E[s^4]-3(E[s^2])^2 \\]

这里假设信号均值为零。实际实现时，还需要考虑信号是否已归一化、是否存在载波相位偏移，以及估计时采用的具体定义。

直观理解：

- \\(C\_{42}\\)：关注复信号幅度及其高阶统计分布。
- \\(C\_{40}\\)：关注复信号的四次幂统计特征，通常对相位结构更敏感。

它们不是直接读取某一个符号，而是对大量采样点进行统计计算。

### 为什么它们可以区分 QAM 和 PSK？

在理想、归一化且符号独立的条件下，不同调制方式通常具有不同的四阶累积量组合。

例如，以下是常见定义下的理论结果：

| 调制方式         | \\(C\_{42}\\) | \\(C\_{40}\\) |
| ------------ | ------------- | ------------- |
| QPSK / 4-PSK | \\(-1\\)      | \\(-1\\)      |
| 8-PSK        | \\(-1\\)      | \\(0\\)       |
| 16-QAM       | \\(-0.68\\)   | \\(-0.68\\)   |

注：这里采用 \\(E[|s|^2]=1\\) 的归一化约定，表中数值为理想星座的理论示例。实际数值会受调制阶数、星座映射、归一化方式及信道影响。

可以看到：

- QPSK 和 16-QAM 的统计特征不同，因此有机会被区分。
- QPSK 和 8-PSK 的 \\(C\_{42}\\) 相同，但 \\(C\_{40}\\) 不同。
- 只使用一个特征可能不够，联合使用多个特征往往更可靠。

这就是常见的 HOC 调制识别方法：计算多个累积量，组成特征向量，再交给分类器进行识别。

\\[ \mathbf{f}= \begin{bmatrix} C\_{20}&C\_{21}&C\_{40}&C\_{42} \end{bmatrix} \\]

实际工程中也常用归一化累积量或其绝对值，降低接收增益变化的影响。

## 4. HOC 的优缺点

优点

- 不需要已知训练序列，适合盲识别。
- 对理想加性高斯噪声具有一定鲁棒性。
- 计算量相对较低，适合传统信号处理系统。
- 能够区分某些二阶统计特征相近的调制方式。

缺点

- 高阶统计量需要足够多的采样点才能稳定估计。
- 在低信噪比下，估计误差可能显著增加。
- 频偏、相位偏移、定时误差、信道失真可能影响特征。
- 不能保证仅凭 \\(C\_{42}\\) 和 \\(C\_{40}\\) 就区分所有调制方式。

# 二、循环谱（Cyclostationary Features）

## 1. 什么是循环平稳特征？

普通平稳信号的统计特性不会随时间改变；而很多通信信号具有周期性统计特征。

例如，数字通信信号具有符号周期 \\(T_s\\)，经过脉冲成形后，其统计结构可能以符号率或其相关频率呈现周期性。

这种现象称为循环平稳性（Cyclostationarity）。

要注意：信号的瞬时幅度不一定每隔一个符号周期就重复。周期性主要体现在均值、相关性等统计特性上。

例如，信号的循环自相关函数可以写为：

\\[ R_x^\alpha(\tau)= \lim\_{T\rightarrow\infty} \frac{1}{T} \int\_{-T/2}^{T/2} x(t+\tau/2)x^\*(t-\tau/2) e^{-j2\pi\alpha t}\\,dt \\]

其中：

- \\(\tau\\)：时延。
- \\(\alpha\\)：循环频率。
- \\(x^\*(t)\\)：复共轭。
- \\(R_x^\alpha(\tau)\\)：信号在循环频率 \\(\alpha\\) 处的循环相关特征。

当某个非零循环频率处的循环相关明显不为零时，就说明信号具有相应的周期性统计结构。

## 2. 什么是循环谱？

对循环自相关函数关于时延 \\(\tau\\) 做傅里叶变换，可以得到循环谱：

\\[ S_x^\alpha(f)= \int\_{-\infty}^{\infty} R_x^\alpha(\tau)e^{-j2\pi f\tau}\\,d\tau \\]

其中：

- \\(f\\)：普通频率，表示信号的频谱位置。
- \\(\alpha\\)：循环频率，表示统计周期对应的频率。

与普通功率谱主要描述能量如何分布在频率轴上不同，循环谱同时分析普通频率 \\(f\\) 和循环频率 \\(\alpha\\)。

因此，它可以揭示普通功率谱不容易显示的信号结构。

## 3. 为什么循环谱能够抗噪？

这是循环谱的核心价值之一。

假设接收信号为：

\\[ r(t)=s(t)+w(t) \\]

其中 \\(s(t)\\) 是通信信号，\\(w(t)\\) 是平稳高斯白噪声。

对于理想平稳噪声，在非零循环频率 \\(\alpha\ne 0\\) 处，理论上有：

\\[ S_w^\alpha(f)=0 \\]

而通信信号由于符号周期、脉冲成形或其他周期性结构，可能在特定循环频率处表现出明显特征。

所以在这些循环频率上：

- 通信信号可能有明显响应。
- 平稳噪声的理论响应为零。

这使得循环谱可以在一定程度上将通信信号与噪声区分开来。

普通功率谱（PSD）

信号和噪声都表现为频谱能量。低信噪比时，信号可能被噪声底掩盖。

[PPT - Cyclostationary Feature Detection PowerPoint Presentation, free download - ID:4067314](https://images.openai.com/static-rsc-4/f5gfBm9ZiM75v3gK7ACyjtKMewB0dC60Bo7NrWpDYbQvWmIyM3k4mM9r3Cjmwj8Hkj5rL3EOpySo1xSo6cn939T6WqyICUaHvV2Y7bX6iDD8XaBRI6VqI7cZp4YFlZcffeQXbbLH3OxGy4eBJgkZIUceLNMt5QDtkC5dQVfO8Sc?purpose=inline)

循环谱（SCF）

利用频率与循环频率之间的统计关系，寻找通信信号的周期性结构。

不过，“抗噪”并不意味着完全不受噪声影响。有限数据长度、频率偏移、非平稳干扰和估计误差仍然可能降低检测性能。

## 4. 循环谱可以检测哪些特征？

常见的循环频率来源包括：

| 特征来源      | 可能提供的信息          |
| --------- | ---------------- |
| 符号率       | 估计符号周期或符号率       |
| 脉冲成形      | 识别成形滤波器或信号结构     |
| 载波及调制结构   | 辅助识别调制方式         |
| 帧结构或周期性导频 | 检测重复结构           |
| 频率偏移相关结构  | 辅助估计频偏，具体取决于信号模型 |

例如，假设一个信号采用符号率 \\(R_s=1/T_s\\)，其循环谱可能在与 \\(R_s\\) 或其他相关周期有关的循环频率上出现峰值。

检测到这些峰值后，就可以进一步估计符号率、判断是否存在通信信号，或者提取供分类器使用的特征。

但不同调制方式的循环谱也可能相似，不能简单认为一个峰值就唯一对应某种调制。

## 5. 循环谱的优缺点

优点

- 能利用信号的周期性结构区分信号与平稳噪声。
- 可用于信号检测、符号率估计和调制识别。
- 在某些低信噪比场景下，比只看功率谱更有效。
- 可提取具有物理意义的特征，便于分析信号结构。

缺点

- 计算量通常高于简单的二阶或四阶统计量。
- 需要足够长的观测数据来稳定估计循环相关。
- 非平稳干扰也可能具有周期性，导致误检。
- 如果信号缺乏明显的可观测周期性特征，优势可能有限。

# 三、HOC 与循环谱的区别

| 对比维度    | 高阶累积量 HOC                | 循环谱                            |
| ------- | ------------------------ | ------------------------------ |
| 核心思想    | 利用高阶概率统计特征               | 利用周期性统计结构                      |
| 主要信息    | 幅度分布、相位结构、非高斯性           | 符号率、周期性相关、频谱相关                 |
| 常见特征    | \\(C\_{40}, C\_{42}\\)   | \\(S_x^\alpha(f)\\) 的峰值、循环频率位置 |
| 抗高斯噪声能力 | 高阶累积量理论上可消除高斯噪声的三阶及以上累积量 | 非零循环频率处的平稳噪声理论响应为零             |
| 计算成本    | 通常较低                     | 通常较高                           |
| 常见用途    | QAM/PSK 分类               | 信号检测、参数估计、调制识别                 |
| 主要限制    | 有限样本下高阶统计量估计不稳定          | 计算量大，且依赖可观测的周期结构               |

# 四、在实际调制识别系统中，怎么结合使用？

一个典型的盲调制识别流程如下：

接收 IQ 信号

采样、预处理、必要的频偏校正

特征提取

HOC

\\(C\_{40}, C\_{42}\\)

循环谱

循环频率、谱峰

特征融合与分类

阈值判决、SVM、随机森林等

输出调制类型

例如 BPSK、QPSK、8-PSK、16-QAM、64-QAM

两种方法是互补的：

- HOC 擅长描述“信号的统计分布是什么样的”。
- 循环谱擅长描述“信号的统计结构以什么周期重复”。

例如，低信噪比条件下，可以先利用循环特征判断信号是否存在、估计符号率，再结合高阶累积量区分调制类型。实际系统是否采用这一顺序，需要根据信号体制、计算资源和目标性能决定。

一句话总结： HOC 主要通过高阶统计分布识别调制方式，循环谱则通过周期性统计结构发现和检测通信信号；两者都不要求事先知道发送的数据，但都需要足够可靠的观测数据才能得到稳定的结果。
