池化层（Pooling Layer）的设计主要考虑三个方面：池化参数如何选、池化层放在哪里、池化后数据形状如何变化。 1D 和 2D 池化的基本原理相同，区别在于操作维度。

## 1. 池化层参数如何选择？

常见参数包括池化核大小（`kernel_size`）、步长（`stride`）、填充（`padding`）和池化方式。

| 参数    | 常见选择                                        | 选择依据                                 |
| ----- | ------------------------------------------- | ------------------------------------ |
| 池化核大小 | 1D：2 或 3；2D：\\(2\times2\\) 或 \\(3\times3\\) | 决定局部区域的汇总范围；核越大，压缩通常越明显。             |
| 步长    | 通常等于池化核大小                                   | 实现非重叠区域的下采样，减少数据尺寸和计算量。              |
| 填充    | 通常为 0（`valid`）                              | 不额外填充，直接对有效区域池化；需要保留边界或控制输出尺寸时再考虑填充。 |
| 池化方式  | 最大池化（Max Pooling）或平均池化（Average Pooling）     | 最大池化保留局部最强响应；平均池化反映局部整体水平。           |

理论依据： 池化通过局部统计汇总降低空间或时间维度，减少后续计算，并在一定程度上增强模型对小范围位置变化的鲁棒性。

注意：池化层通常没有可训练参数，因此不会像卷积层那样增加可学习权重。

## 2. 池化层通常放在哪里？

输入数据

卷积层 → 激活函数

池化层（可选）

后续卷积层 → 特征提取

分类或回归输出

常见放置原则：

- 卷积层之后：先提取特征，再对特征进行压缩，是经典 CNN 的常见设计。
- 网络浅层：可以较早池化，以减少后续计算，但过早下采样可能丢失细节。
- 网络中间层：通常在需要降低特征图尺寸、扩大后续层有效感受野时使用。
- 网络深层：可以使用全局平均池化（Global Average Pooling），将每个通道的空间特征汇总成一个值。

池化不是必需的。现代网络也常通过步长大于 1 的卷积完成下采样。

## 3. 池化层会怎样改变输入形状？

### 1D 池化

输入张量通常为：

\\[ (B,C,L) \\]

其中 \\(B\\) 为批次大小，\\(C\\) 为通道数，\\(L\\) 为序列长度。

例如，输入形状为 \\((32,16,100)\\)，使用核大小为 2、步长为 2 的池化：

\\[ (32,16,100)\rightarrow(32,16,50) \\]

序列长度减半，批次大小和通道数不变。

### 2D 池化

输入张量通常为：

\\[ (B,C,H,W) \\]

例如，输入形状为 \\((32,64,32,32)\\)，使用 \\(2\times2\\) 池化，步长为 2：

\\[ (32,64,32,32)\rightarrow(32,64,16,16) \\]

高和宽减半，批次大小和通道数不变。

### 输出尺寸计算公式

对于每个被池化的维度（1D 的长度或 2D 的高度、宽度）：

\\[ L\_{\mathrm{out}}= \left\lfloor \frac{L\_{\mathrm{in}}+2P-K}{S}+1 \right\rfloor \\]

其中：

- \\(L\_{\mathrm{in}}\\)：输入长度或空间尺寸；
- \\(K\\)：池化核大小；
- \\(P\\)：填充；
- \\(S\\)：步长。

该公式适用于常见池化设置；若使用 `ceil_mode=True`，输出尺寸计算会有所不同。

## 4. 池化层对各维度的影响总结

| 维度                    | 是否改变 | 原因                  |
| --------------------- | ---- | ------------------- |
| 批次大小 \\(B\\)          | 不变   | 池化独立处理每个样本。         |
| 通道数 \\(C\\)           | 通常不变 | 每个通道分别进行池化，不进行通道混合。 |
| 序列长度 \\(L\\)          | 可能缩小 | 1D 池化压缩时间或序列维度。     |
| 高度 \\(H\\)、宽度 \\(W\\) | 可能缩小 | 2D 池化压缩空间维度。        |

实际设计建议： 如果任务依赖精细的时间定位或图像细节，不宜过度池化；如果更关注整体模式、希望减少计算量，可以适当下采样。对于 1D 时间序列尤其要注意：池化会减少时间分辨率，可能丢失短暂峰值或局部变化。
