1D 和 2D 卷积层参数的选取，核心依据是数据的结构特征、感受野需求、特征表达能力、计算成本及输出尺寸要求。

| 参数                 | 选取参考方向                                                                       | 理论依据                                             |
| ------------------ | ---------------------------------------------------------------------------- | ------------------------------------------------ |
| 输入通道（In Channels）  | 由输入数据决定，如多变量时序的变量数、图像的 RGB 通道数，或上一层的输出通道数。                                   | 输入张量的通道维度必须与卷积核的输入通道维度匹配。                        |
| 输出通道（Out Channels） | 根据特征复杂度和模型容量调整；复杂任务可增加通道，但需平衡计算量与过拟合风险。                                      | 每个输出通道对应一组可学习的卷积核，用于提取不同特征；参数量与输出通道数近似成正比。       |
| 卷积核大小（Kernel Size） | 1D 常用 3、5、7；2D 常用 \\(3\times3\\)、\\(5\times5\\)。局部特征用小核，需要更大感受野时可堆叠卷积或增大核尺寸。 | 卷积核决定局部感受野；较大卷积核可捕获更大范围的空间或时间依赖，但增加参数量和计算量。      |
| 填充（Padding）        | 若要保持输出尺寸，通常选 `same`；若希望逐步缩小特征图，可选 `valid` 或适当填充。                             | 控制边界信息的处理及输出尺寸。对于步长为 1 的卷积，适当填充可保持输入与输出的长度或宽高一致。 |
| 步长（Stride）         | 常用 1 提取细粒度特征；需要降采样时可取 2 或更大。                                                 | 步长决定卷积核每次移动的距离，影响输出分辨率、计算量及细节保留程度。               |

### 理论与实践依据

\- 输出尺寸公式（1D 各空间维度通用，2D 分别计算高度和宽度）：

\\[ L\_{\text{out}}= \left\lfloor\frac{L\_{\text{in}}+2P-D(K-1)-1}{S}+1\right\rfloor \\]

其中 \\(P\\) 为填充，\\(K\\) 为核大小，\\(S\\) 为步长，\\(D\\) 为膨胀率。

\- 参数量公式（含偏置）：

\\[ N\_{\text{params}}=C\_{\text{out}} (C\_{\text{in}}K+1) \\]

此式适用于标准 1D 卷积；标准 2D 卷积将 \\(K\\) 替换为 \\(K_hK_w\\)。

\- 设计原则：优先依据数据特征和任务需求确定感受野与输出尺寸，再调整通道数以控制模型容量，最后通过验证集实验、消融实验或超参数搜索确定最优配置。上述常用数值是实践经验，并非适用于所有任务的理论最优值。
