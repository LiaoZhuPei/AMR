1D 和 2D 卷积层参数的选取，核心依据是数据的结构特征、感受野需求、特征表达能力、计算成本及输出尺寸要求。

| 参数                 | 选取参考方向                                                                       | 理论依据                                             |
| ------------------ | ---------------------------------------------------------------------------- | ------------------------------------------------ |
| 输入通道（In Channels）  | 由输入数据决定，如多变量时序的变量数、图像的 RGB 通道数，或上一层的输出通道数。                                   | 输入张量的通道维度必须与卷积核的输入通道维度匹配。                        |
| 输出通道（Out Channels） | 根据特征复杂度和模型容量调整；复杂任务可增加通道，但需平衡计算量与过拟合风险。                                      | 每个输出通道对应一组可学习的卷积核，用于提取不同特征；参数量与输出通道数近似成正比。       |
| 卷积核大小（Kernel Size） | 1D 常用 3、5、7；2D 常用 \\(3\times3\\)、\\(5\times5\\)。局部特征用小核，需要更大感受野时可堆叠卷积或增大核尺寸。 | 卷积核决定局部感受野；较大卷积核可捕获更大范围的空间或时间依赖，但增加参数量和计算量。      |
| 填充（Padding）        | 若要保持输出尺寸，通常选 `same`；若希望逐步缩小特征图，可选 `valid` 或适当填充。                             | 控制边界信息的处理及输出尺寸。对于步长为 1 的卷积，适当填充可保持输入与输出的长度或宽高一致。 |
| 步长（Stride）         | 常用 1 提取细粒度特征；需要降采样时可取 2 或更大。                                                 | 步长决定卷积核每次移动的距离，影响输出分辨率、计算量及细节保留程度。               |

### 理论与实践依据

\- 输出尺寸公式（1D 各空间维度通用，2D 分别计算高度和宽度）：

\\[ L\_{\text{out}}= \left\lfloor\frac{L\_{\text{in}}+2P-D(K-1)-1}{S}+1\right\rfloor \\]

其中 \\(P\\) 为填充，\\(K\\) 为核大小，\\(S\\) 为步长，\\(D\\) 为膨胀率。

\- 参数量公式（含偏置）：

\\[ N\_{\text{params}}=C\_{\text{out}} (C\_{\text{in}}K+1) \\]

此式适用于标准 1D 卷积；标准 2D 卷积将 \\(K\\) 替换为 \\(K_hK_w\\)。

\- 设计原则：优先依据数据特征和任务需求确定感受野与输出尺寸，再调整通道数以控制模型容量，最后通过验证集实验、消融实验或超参数搜索确定最优配置。上述常用数值是实践经验，并非适用于所有任务的理论最优值。

这几个问题的核心是：通道数决定特征表达能力，卷积核大小决定局部感受野，它们都没有严格的理论固定值，但有成熟的设计经验和理论依据。

## 1. 第一层卷积的输出通道数怎么确定？

第一层输出通道数没有直接的理论计算公式，通常根据输入数据复杂度、模型规模和计算资源确定。

- 简单数据或小模型：可以从 8、16、32 个通道开始尝试。
- 复杂数据或高维输入：可以从 32、64 个通道开始尝试。
- 最终选择：比较不同通道数在验证集上的效果，同时考虑参数量、计算量和过拟合风险。

理论依据：每个输出通道对应一组独立的可学习卷积核，可以提取一种或一类特征。通道数越多，模型潜在的特征表达能力越强，但收益并非线性增长。

## 3. 卷积核大小在上下层之间有默认规则吗？

没有必须遵守的规则，但有以下常见经验：

| 网络层次       | 常用卷积核         | 设计目的             |
| ---------- | ------------- | ---------------- |
| 浅层         | 3 或 5         | 提取局部细节、边缘或短期变化   |
| 中间层        | 3             | 逐层组合局部特征，扩大有效感受野 |
| 深层         | 3，或配合更大感受野的设计 | 提取复杂、高层次特征       |
| 特征融合或通道变换层 | 1             | 调整通道数，不直接扩大空间感受野 |

- 2D 卷积：常用连续的 \\(3\times3\\) 卷积，而不是每深入一层就增大卷积核。
- 1D 卷积：常用长度为 3、5 或 7 的卷积核。对于时间序列，可以根据需要捕获的时间跨度选择核大小。
- 扩大感受野：可以通过堆叠多个小卷积核、增大步长或使用空洞卷积实现，不一定需要增大卷积核。

例如，两个连续的 \\(3\times3\\) 卷积，在步长为 1 且不考虑边界效应时，理论感受野相当于 \\(5\times5\\)，但参数量更少（相同输入、输出通道数为 \\(C\\) 时，两个卷积约为 \\(18C^2\\)，单个 \\(5\times5\\) 卷积约为 \\(25C^2\\)）。

## 4. 实际设计时怎么选？

如果没有特定架构要求，可以先采用以下基线：

| 层     | 输出通道     | 卷积核 | 步长        |
| ----- | -------- | --- | --------- |
| 第 1 层 | 16 或 32  | 3   | 1         |
| 第 2 层 | 32 或 64  | 3   | 1         |
| 第 3 层 | 64 或 128 | 3   | 1 或 2     |
| 后续层   | 逐步增加或保持  | 3   | 根据降采样需求选择 |

填充通常配合步长设置，以满足期望的输出尺寸。

最重要的结论： 通道数一般根据模型容量和计算预算调整；卷积核大小一般根据目标特征的局部范围确定。两者都应先选合理的初始值，再通过验证集和消融实验确定，而不是依据层数套用固定公式。
